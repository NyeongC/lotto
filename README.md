# 🍀 오늘의 로또

**문장 하나로 오늘의 번호를 뽑는** 가벼운 로또 번호 생성기.
뽑은 번호가 과거 회차에 나왔다면 몇 등이었고 얼마를 받았을지도 알려줍니다.

👉 **[nyeongc.github.io/lotto](https://nyeongc.github.io/lotto/)**

> 번호에 의미는 없습니다. 재미로만 즐겨주세요.

## 이렇게 써요

| 탭 | 사용법 |
|---|---|
| **기본** | `+` 버튼(또는 Enter)을 누르면 무작위 번호 한 줄 |
| **문장** | 아무 문장이나 입력하고 Enter → 그 문장의 "오늘의 번호" |

- 같은 날 같은 문장을 넣으면 **항상 같은 번호**가 나옵니다. 날짜가 바뀌면 번호도 바뀝니다.
- 번호가 과거에 당첨됐다면 줄 아래에 표시됩니다.
  ```
  🎯 1043회(2022.11.26)였다면 3등 · 1,318,494원
  ```
  1–3등은 1회부터 전체 회차, 4등은 최근 3년(156회차)을 비교합니다. 약 5줄에 1줄꼴로 나와요.
- 기록은 브라우저에만 저장됩니다 (탭별 최대 50줄).

## 문장 → 번호 알고리즘: 클로버 v2

```
문장 ─ 공백 정리 ─ 한글 획수 계산 ─┐
날짜(YYYYMMDD) ───────────────────┼─ 128bit 해시 ─ 난수기 ─ 획수만큼 굴리기 ─ 7개 추첨
버전(clover-v2) ──────────────────┘
```

1. **획수 계산** — 한글 음절을 초성·중성·종성으로 분해해 자모 획수를 더합니다. (`가` = ㄱ1 + ㅏ2 = 3획)
2. **128bit 해시** — `clover-v2 | 문장 | 획수 | 날짜`를 cyrb128로 해시합니다.
3. **난수기** — 해시값으로 sfc32(128bit 상태) 난수기를 만듭니다.
4. **획수만큼 굴리기** — 번호를 뽑기 전에 `12 + (획수 % 32)`번 굴립니다.
5. **추첨** — 거절 샘플링으로 1–45 중 7개를 균등하게 뽑습니다. 앞 6개는 본번호, 7번째는 보너스.

서로 다른 문장 30만 개로 검증한 결과, 1–45의 출현 빈도와 번호쌍 분포 모두 균등했습니다.

## 만든 방식

- 순수 HTML / CSS / JavaScript, 빌드 단계 없음 — `index.html`을 더블클릭해도 동작
- 외부 의존성은 [Pretendard](https://github.com/orioncactus/pretendard) 폰트 하나
- 역대 당첨 데이터는 `data.js` (1회~최신), `scripts/update-draws.mjs`로 갱신
- GitHub Pages로 배포 · 라이트/다크 모드 · 모바일 우선

## 개발 기록

| 단계 | 내용 |
|---|---|
| **v1 첫 배포** | 기본·문장 탭, 획수 + 날짜 기반 "오늘의 번호", 공 떨어지는 애니메이션, 복사, 로컬 기록 |
| **역대 당첨 비교** | 1회부터의 당첨 데이터를 넣고, 3등 이상이었으면 회차·등수·당첨금 표시 |
| **알고리즘 클로버 v2** | "1이 너무 자주 나온다"는 의문에서 출발. 검증해보니 기존 방식도 균등했지만 128bit 해시·난수기, 거절 샘플링, "획수만큼 굴리기"로 우리만의 알고리즘으로 교체 |
| **4등 확대** | 3등 이상만으로는 30줄에 1번꼴이라 심심해서, 최근 3년 4등까지 포함 → 약 5줄에 1번 |

## 데이터 갱신

새 회차가 나오면:

```bash
node scripts/update-draws.mjs
```

`data.js`가 바뀌면 커밋 → 푸시하면 GitHub Pages가 자동으로 다시 배포합니다.
